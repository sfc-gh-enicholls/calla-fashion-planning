Data sharing

Demand out, evidence back

Supplier data share

The revised demand signal and order requirement publish into the vendor's own Snowflake account. The same share defines the Digital Product Passport fields returned against the order line.

  • Fibre composition by weight (per component)
  • Country of origin — spinning, weaving, dyeing, assembly
  • Tier-2 mill identity and facility ID
  • Chemical inputs — REACH SVHC declaration
  • Recycled content share and certification
  • Care, repair and end-of-life routing

Compliance evidence is data, not a filing cabinet

One supplier record

Audit reports, test certificates and supplier declarations still arrive as documents, but they do not stay trapped there. AI_EXTRACT parses the fields, Cortex Search retrieves the evidence, and both join back to the same supplier keys as lead time, spare capacity and OTIF.

Tagging and masking controls keep the record governed while letting buying, sourcing and sustainability resolve one answer from one row.

Generated SQL
Semantic view: CALLA.MERCH.SV_SOURCING_COMPLIANCE
WITH active_suppliers AS (
  SELECT
    v.vendor_id,
    v.vendor_name,
    v.country,
    v.lead_time_weeks,
    c.audit_grade,
    c.audit_expiry_weeks,
    c.subcontractor_disclosure,
    c.reach_zdhc,
    c.traceability_depth,
    c.dpp_completeness,
    SUM(CASE
      WHEN po.delivery_week BETWEEN 18 AND 24
      THEN po.units ELSE 0 END) AS open_units_next_six_weeks,
    MAX(v.capacity_units) AS capacity_units,
    SUM(CASE
      WHEN w.iso_week BETWEEN 18 AND 22
      THEN w.units_plan ELSE 0 END) AS demand_window_units,
    SUM(CASE
      WHEN w.iso_week > 22
       AND w.iso_week <= 24
      THEN w.units_plan ELSE 0 END) AS chase_tail_units,
    AVG(s.retail_price) AS retail_price,
    AVG(s.cost_price) AS cost_price
  FROM CALLA.MERCH.DIM_VENDOR AS v
  JOIN CALLA.MERCH.DIM_STYLE AS s ON s.vendor_id = v.vendor_id
  LEFT JOIN CALLA.MERCH.FCT_PURCHASE_ORDER AS po
    ON po.vendor_id = v.vendor_id
   AND po.style_code = 'DN-FLR-002'
   AND po.status IN ('firm', 'modifiable')
  LEFT JOIN CALLA.MERCH.FCT_TRADING_WEEK AS w
    ON w.style_code = s.style_code
   AND w.cycle = 'SS26'
  JOIN CALLA.MERCH.DIM_VENDOR_COMPLIANCE AS c
    ON c.vendor_id = v.vendor_id
  WHERE s.style_code = 'DN-FLR-002'
  GROUP BY
    v.vendor_id,
    v.vendor_name,
    v.country,
    v.lead_time_weeks,
    c.audit_grade,
    c.audit_expiry_weeks,
    c.subcontractor_disclosure,
    c.reach_zdhc,
    c.traceability_depth,
    c.dpp_completeness
),
scored AS (
  SELECT
    vendor_name,
    country,
    lead_time_weeks,
    audit_grade,
    audit_expiry_weeks,
    subcontractor_disclosure,
    reach_zdhc,
    traceability_depth,
    dpp_completeness,
    LEAST(capacity_units, GREATEST(demand_window_units, 0)) AS six_week_capacity,
    retail_price - cost_price AS full_margin_per_unit,
    retail_price * 0.72 - cost_price AS late_margin_per_unit,
    CASE
      WHEN audit_expiry_weeks > lead_time_weeks
       AND subcontractor_disclosure = 'complete'
       AND reach_zdhc = 'current'
       AND dpp_completeness >= 70
      THEN 1 ELSE 0 END AS qualifies,
    CASE
      WHEN audit_expiry_weeks > lead_time_weeks
       AND subcontractor_disclosure = 'complete'
       AND reach_zdhc = 'current'
       AND dpp_completeness >= 70
      THEN 0
      ELSE 18000
        + CASE WHEN subcontractor_disclosure <> 'complete' THEN 12000 ELSE 0 END
        + CASE WHEN dpp_completeness < 70 THEN 9500 ELSE 0 END
    END AS remediation_cost,
    CASE
      WHEN audit_expiry_weeks > lead_time_weeks
       AND subcontractor_disclosure = 'complete'
       AND reach_zdhc = 'current'
       AND dpp_completeness >= 70
      THEN 0
      ELSE 5 + CASE WHEN subcontractor_disclosure = 'undisclosed' THEN 3 ELSE 0 END
    END AS remediation_weeks
  FROM active_suppliers
)
SELECT
  vendor_name,
  six_week_capacity,
  audit_grade,
  audit_expiry_weeks,
  subcontractor_disclosure,
  reach_zdhc,
  traceability_depth,
  dpp_completeness,
  qualifies,
  ROUND(six_week_capacity * full_margin_per_unit) AS headline_margin,
  ROUND(
    CASE
      WHEN qualifies = 1 THEN six_week_capacity * full_margin_per_unit
      ELSE GREATEST(4 - remediation_weeks, 0) / NULLIF(4, 0) * six_week_capacity * full_margin_per_unit
         + LEAST(remediation_weeks, 4) / NULLIF(4, 0) * six_week_capacity * late_margin_per_unit
         - remediation_cost
    END
  ) AS achievable_margin
FROM scored
ORDER BY achievable_margin DESC, vendor_name;
