Ecommerce is running +11.2% to plan and stores -12.3%, so the total looks closer to plan than either channel is. Ecommerce has taken 4.2 points of share it was not planned to carry, and it returns at four times the store rate — so those units are worth less than they read here.
How this was derived

Channel shares are apportioned from the same style-week totals, so the mix shift is a genuine redistribution rather than extra demand appearing in one channel.

Analyst query

The same question a planner would ask, answered against the semantic view the plan is built on.

“How am I performing month to date and season to date, and where is the variance coming from?”
Season to date is -2.1% to plan on 314,808 units and +4.0% against last year. Month to date is -4.0%, so the gap is widening. The variance is not evenly spread: it concentrates in channel mix rather than in total demand.

Generated SQL
Semantic view: CALLA.MERCH.SV_TRADING_WEEK
WITH mtd AS (
    SELECT
        c.retail_month_no,
        SUM(w.units_sold)                          AS units_sold,
        SUM(w.units_plan)                          AS units_plan
    FROM CALLA.MERCH.FCT_TRADING_WEEK w
    JOIN CALLA.MERCH.DIM_CALENDAR    c ON c.iso_week = w.iso_week
    WHERE c.cycle = 'SS26'
      AND w.iso_week <= 18
    GROUP BY c.retail_month_no
)
SELECT
    retail_month_no,
    units_sold,
    units_plan,
    DIV0(units_sold - units_plan, units_plan) * 100 AS var_to_plan_pct
FROM mtd
ORDER BY retail_month_no
